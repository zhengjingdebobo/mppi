void VESC_SendRPM(uint8_t vesc_id, int32_t rpm) 
{ 
    uint32_t ext_id = ((uint32_t)3 << 8) | vesc_id;   // CAN_PACKET_SET_RPM 
    TxMessage.IDE   = CAN_Id_Extended; 
    TxMessage.RTR   = CAN_RTR_Data; 
    TxMessage.ExtId = ext_id; 
    TxMessage.DLC   = 8; 
    TxMessage.Data[0] = (rpm >> 24) & 0xFF; 
    TxMessage.Data[1] = (rpm >> 16) & 0xFF; 
    TxMessage.Data[2] = (rpm >> 8) & 0xFF; 
    TxMessage.Data[3] = (rpm)       & 0xFF; 
    TxMessage.Data[4] = 0; 
    TxMessage.Data[5] = 0; 
    TxMessage.Data[6] = 0; 
    TxMessage.Data[7] = 0;

}

关于标准帧和扩展帧的区别 
标准帧（大疆 DJI RoboMaster 设备采用） 
标准帧使用 11 位标识符（Identifier） ，标识符范围从 0x000 到 0x7FF。设备在
接收标准帧时通过 IDE=0 进行识别，并从 StdId 字段中读取标识符。 
扩展帧（VESC CAN 协议采用） 
扩展帧使用 29 位标识符，由 11 位基本 ID 与额外的 18 位扩展字段组成，可用
于复杂系统或需要大量定义消息类型的应用。扩展帧在接收时通过 IDE=1 区分，
并从 ExtId 字段读取完整的 29 位标识符。  
标准帧和扩展帧可以同时存在，同时使用，不会发生冲突。在如下的接收中断
